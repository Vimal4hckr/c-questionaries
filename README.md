# C Programming Question Bank

Welcome to **C Programming Question Bank**, a collection of C programming questions, practice programs, and sample answers designed to help students learn programming fundamentals and improve problem-solving skills.

This repository is useful for beginners practising C programming, preparing for laboratory assessments, and strengthening their understanding of programming logic.

## 📚 Topics Covered

- **C Fundamentals:** Program structure, syntax, variables, and data types
- **Input and Output:** `printf()` and `scanf()`
- **Operators:** Arithmetic, relational, logical, and assignment operators
- **Conditional Statements:** `if`, `if-else`, nested `if`, and `else-if`
- **Ternary Operator:** Conditional expressions using `?:`
- **Problem Solving:** Writing and testing small C programs
- **Programming Practice:** Questions, exercises, and sample solutions

## 🚀 Getting Started

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/c-questionaries.git
cd c-questionaries
```

### Step 2: Compile a C Program

Save your source code with a `.c` extension and compile it using GCC:

```bash
gcc program.c -o program
```

### Step 3: Run the Program

**Windows:**

```cmd
program.exe
```

**Linux/macOS:**

```bash
./program
```

Replace `program.c` with your actual C source filename.
